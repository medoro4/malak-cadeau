# مكتبة ملك — النسخة بالنشر التلقائي

## الفرق عن النسخة السابقة
هذه النسخة تنشر أي تعديل مباشرة إلى GitHub بضغطة واحدة — بلا نسخ ولصق يدوي.
كل من يفتح الموقع (من أي جهاز) يشوف التحديث خلال ثوانٍ.

## الإعداد لمرة واحدة

1. من GitHub: صورة حسابك (أعلى يمين) → **Settings**
2. أسفل القائمة اليسار → **Developer settings**
3. **Personal access tokens → Tokens (classic) → Generate new token (classic)**
4. الاسم: `malak-site` — المدة: **No expiration**
5. فعّل صلاحية **repo** فقط (الصندوق الرئيسي) → **Generate token**
6. انسخ المفتاح فورًا (يظهر مرة واحدة فقط، يبدأ بـ `ghp_`)

## الاستخدام من الموقع

1. افتح الموقع → أسفل الصفحة **إدارة** → كلمة السر: `malak2025`
2. أول مرة فقط: الصق مفتاح GitHub في الصندوق واضغط **حفظ والمتابعة**
   (يُحفظ في هذا المتصفح/الهاتف فقط، لا تحتاج تكراره إلا إذا بدّلت الجهاز أو مسحت بيانات المتصفح)
3. أضف أو عدّل أو احذف منتجات — كل زر يحفظ وينشر مباشرة.
4. بانتظار "جاري النشر…" لثوانٍ قليلة، ثم رسالة خضراء تؤكد النشر.

## ملاحظات أمان
- المفتاح لا يُخزَّن في كود الموقع، فقط في متصفح الجهاز اللي دخلت منه.
- إذا حدا غيرك استخدم نفس الجهاز ودخل لوحة الإدارة، بقدر يشوف نفس الصلاحية.
  لهذا زر **"تغيير المفتاح"** بالأعلى يمسحه من المتصفح عند الحاجة.
- إذا ضاع المفتاح أو انكشف، احذفه من GitHub (Settings → Developer settings → نفس المكان) وأنشئ واحدًا جديدًا.

## إضافة صور
اضغط الصورة على squoosh.app (أقل من 200KB)، ثم ارفعها في مجلد `images` على GitHub،
واكتب بخانة الصورة: `images/اسم-الصورة.jpg`

## تعديل معلومات المحل
كل الإعدادات أعلى قسم `<script>` تحت `const CFG`.
تأكد أن `ghOwner` و `ghRepo` مطابقين لاسم حسابك ومستودعك بالضبط.
